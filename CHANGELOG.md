## [1.0.0] - Initial public release

- Structured OCR pipeline architecture
- Multi-stage processing engine
- OCR language profile system

- Line-based text structuring
- TXT export
- ODT export
- Configurable OCR parameters
- Qt6-based graphical interface

### Technical

- RAM-first processing architecture
- Deterministic pipeline stages
- Structured TSV → LineTable conversion
- Centralized logging system
- Centralized progress management
