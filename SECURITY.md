# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OCRtoODT, please report it responsibly.

Do **not** open a public issue describing the vulnerability in detail.

Instead, contact the maintainer directly:

GitHub:  
https://github.com/Rostislav62

Please include:

- description of the issue
- steps to reproduce
- potential impact
- suggested fix (if available)

## Supported Versions

Currently only the latest release version is supported for security updates.

Older versions may not receive fixes.

## Scope

This policy applies to:

- the OCRtoODT application
- bundled third-party libraries
- packaging and distribution files
